# 双智能体复核

## 原理

单个智能体写代码时会「自我感觉良好」，因为它刚才是自己生成的。

## 做法

- **generator**：只负责读作用域内文件 → 产出候选迁移。
- **reviewer**：只负责挑错（正确性/内存安全/遗漏/越界）。

## 为什么这么做

让 AI「自己审自己」几乎无效——两个角色必须用**不同的系统提示词、不同的目标函数**：
一个求「做出来」，一个求「挑出毛病」。这比让一个模型自问自答有用得多。

## 复用要点

复核不是「再生成一遍」，而是带着「找茬清单」逐条核对。见 `agents/reviewer.py` 的
`REVIEW_CHECKLIST`。
