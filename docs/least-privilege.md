# 最小权限作用域

## 原理

给智能体的权限越窄，它「越界改坏」的可能性越低。

## 做法

- **文件作用域**（read_scope / write_scope）：只让它读必要的上下文、只让它写目标文件。
- **工具作用域**（tool_scope）：只开放白名单工具。

## 为什么这么做

最小权限不是限制能力，而是**把错误隔离在最小的可控单元里**。AI 一次改一个文件、
只看几个依赖，出了错也好定位、好回滚。

## 复用要点

这条原则和「安全」里的 least privilege 同源。给 LLM 造工具时，永远先问：
这个任务最少需要哪些文件、哪些工具？能少给就不多给。
